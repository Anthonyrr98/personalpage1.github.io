晶体场强的计算

请输入同一种 d3 离子的谱峰波长，单位均为 nm：T2、T1 为激发峰，2E 为发射峰；T1 波长应短于 T2。

适用范围：本页按 d3 离子的能级跃迁计算 B、C 和 β（如 Mn4+、Cr3+）。Fe3+ 为 d5，不能直接使用这组输入和公式计算其 β。

换算关系：波数 E (cm⁻¹) = 107 / 波长 (nm)。两个 β 输出分别使用对应离子的自由离子参数：Mn4+ 的 B₀ = 1160、C₀ = 4303；Cr3+ 的 B₀ = 918、C₀ = 3850，单位均为 cm⁻¹。请只采用与输入谱峰所属离子对应的 β；结果是基于所选峰位的估算值。

参考公式：

$$E\,(\mathrm{cm}^{-1}) = \frac{10^{7}}{\lambda\,(\mathrm{nm})}$$ $$D q = \frac { E ( ^ { 4 } T _ { 2 } - 4 A _ { 2 } ) } { 1 0 } $$ $$x = \frac { E ( ^ { 4 } A _ { 2 } - ^ { 4 }T _ { 1 } ) - E ( ^ { 4 }A _ { 2 } - ^ { 4 } T _ { 2 } ) } { D q } $$ $$\frac { D q } { B } = \frac { 1 5 ( x - 8 ) } { ( x ^ { 2 } - 1 0 x ) } $$ $$\frac { E ( ^ { 2 } E _ { g } \rightarrow ^ { 4 } A _ { 2 g } ) } { B } = \frac { 3 . 0 5 C } { B } - \frac { 1 . 8 B } { D q } + 7 . 9 $$ $$\beta _ { 1 } = \sqrt { ( \frac { B } { B _ { 0 } } ) ^ { 2 } + ( \frac { C } { C _ { 0 } } ) ^ { 2 } } $$
